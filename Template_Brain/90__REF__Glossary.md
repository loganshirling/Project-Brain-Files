# Glossary

- Brain Files: A small markdown canon used as the inspectable source of truth for a ChatGPT Project.
- Template repository: A GitHub repository used to generate new repositories with the same starting structure and files.
- GitHub Actions: GitHub’s workflow automation system for CI/CD and repository tasks.
- Drift: The gap between current chat assumptions, repo reality, and the markdown canon.
- Canon: The specific markdown files treated as authoritative for this project.
